# Organización de los archivos

El repositorio público contiene el análisis, sus datos y los documentos técnicos. El firmware y la presentación se mantienen en el proyecto de trabajo.

| Ruta pública actual | Contenido |
| --- | --- |
| `datos/lote3/` | Excel originales del análisis vigente |
| `datos/lote1/`, `datos/lote2/` | Archivo histórico |
| `graficas/`, `tablas/` | Resultados reproducibles |
| `docs/` | Resumen, informe, diccionario y reproducción |
| Raíz | Notebook, scripts, tablero autónomo, dependencias, README, registro de cambios y reglas de exclusión |

Para el proyecto de trabajo se propone conservar `firmware/` y `basedatos/`, documentar esquemas y materiales en `hardware/`, mantener fotos y medidas verificadas en `maqueta/`, y agrupar análisis, datos, gráficos y documentos como están aquí. La presentación y sus fondos se mantienen en `presentacion/` para el equipo. Agregar `LICENSE` cuando el equipo defina los permisos de reutilización.
